# CSS Dropdown & List Collection

A single-page project that showcases **30 different UI styles** built using **pure HTML and CSS**.

The page includes:

* **15 custom dropdown (`<select>`) styles**
* **15 styled list (`<ul>` / `<ol>`) designs**

Each component demonstrates modern CSS techniques such as gradients, glass effects, custom markers, and decorative list layouts.

This project is useful as a **design reference and learning resource** for styling common UI elements without JavaScript.

## 🧠 How It Works

### Dropdown Styles

* Real `<select>` elements are used for **native accessibility and keyboard support**.
* Each dropdown style uses classes:

```

.dd-1 → .dd-15

```

* Visual enhancements include gradients, borders, shadows, and custom arrow icons.

---

### List Styles

* Lists are styled using `<ul>` and `<ol>` elements.
* Each style uses classes:

```

.ls-16 → .ls-30

```

* CSS techniques modify markers, numbering, spacing, and decorative elements.

## 🎨 CSS Techniques Used

This project demonstrates several modern CSS techniques:

* Gradient backgrounds
* Glassmorphism effects

* Metallic shine effects

## ♿ Accessibility

Accessibility considerations include:

* Real `<select>` elements for keyboard navigation
* High contrast text and backgrounds
* `:focus-visible` rings for keyboard users
* `color-scheme: dark` support for dropdown popups (in supported browsers)
